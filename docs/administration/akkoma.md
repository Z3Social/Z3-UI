# Akkoma features

Z3-UI supports some Akkoma features (and will support more features as the time passes).

## Bubble timeline

Akkoma allows the administrators to handpick a few instances to create a new timeline, showing all public posts from said instances.  
Z3-UI shows a `Curated Timeline` entry in user's settings. If enabled, it will replace the `fediverse timeline` with the Akkoma's `bubble timeline`.
